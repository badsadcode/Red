# Oregon Lakehouse *(working title)*

*Some days you fish. Some days you descend into the impossible.*

A first-person browser game from **Bad Ideas Works**. You're on vacation in a log
cabin beside a lake in the Oregon woods. Fish, chop wood, cook, forage, sleep,
listen to the rain. Then one evening the sky turns red, and the old padlocked
door at the foot of the mountain stops being just an old utility door.

The design brief lives in [`docs/DESIGN.md`](docs/DESIGN.md).

## Play it

It is a static site, with no build step. Serve the folder and open it:

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>. Three.js r160 comes from jsDelivr via an import map,
so you need an internet connection for the first load.

**Controls:** WASD walk · Shift run · Space jump (and swim up) · Mouse look · **E** interact ·
Click use tool (hold to reel) · **1/2/3** hands / axe / rod · **F** flashlight · **R** swap
batteries · **Q** eat · **Tab** backpack · **M** map · **Esc** pause & settings.

### Windows .exe

```bash
./tools/build_exe.sh
```

That writes `dist/OregonLakehouse.exe`: one self-contained file, about 15 MB, with the
game and three.js embedded, so it runs offline. Double-click it and the game opens in an
Edge app window. It quits on its own when you close that window, and saves persist between
launches.

## What's in this slice

**Above: the valley.**
- A lake with real reflections, an 800 m forest of CC0 Quaternius pines (with LOD),
  mossy rocks, berry bushes, fallen logs, a dock and an old fire lookout you can climb.
- The cabin: log walls, porch, wood stove (real shadows from the firelight), lamp, bed,
  pantry chest, workbench and a broken radio.
- Day and night, plus weather that is mostly some flavour of grey: mist, overcast, drizzle,
  rain, storms with lightning, and the occasional sunbreak.
- The loop: fish (cast, wait for the bite, reel against the tension), chop firewood, light
  the stove, cook trout or trout-and-chanterelle stew, eat, sleep. Energy is gentle.
  Nothing kills you up here.
- The red sky. It comes once you've settled in, at dusk, and never before you've had a
  quiet day or two.

**Below: the Cascade Basin Applied Research Facility.**
- A hand-built vestibule and reception, then **Freight Shaft 1**: a 700 m vertical shaft
  with a freight platform that rides down past seven sector landings.
- Seven sectors generated by [BadLevel](https://github.com/badsadcode/BadLevel) and then
  frozen, so they never re-roll and you can learn them like a real building:
  B-1 Administration, B-2 Commons, B-3 Research Labs, B-4 Hydroponics (flooded beds,
  grow lights), B-5 Power & Reactor (huge), B-6 Flooded Maintenance, and B-7 (scratched
  off the panel).
- Keycards, sliding doors, secret panels, lifts, ladders, water, chasms, dart traps,
  supply lockers, salvage, 30+ notes, and a freight relay per level that powers the
  next landing.
- Shades: tall dark things that hate your flashlight and don't much like your axe.
  There are few of them on the upper levels and more the deeper you go. If one gets you,
  you wake up in your own bed with lighter pockets.
- Salvage goes back to the cabin workbench: a wider flashlight beam, longer battery life,
  a better reel, and a repaired radio, which has started picking up things it shouldn't.
- What's at the bottom is for you to find.

## How it's built (for whichever AI inherits this mess)

| File | What it does |
|---|---|
| `src/main.js` | Boot, the game loop, travel between areas, interaction picking, save/load |
| `src/retro.js` | The PS1 look: vertex snapping, affine texture mapping, baked-light material patch, low-res render target, dithering and colour depth, settings |
| `src/physics.js` | Box/slope/wedge/cylinder/heightfield collider, and the player controller (stairs, ladders, swimming) |
| `src/surface.js` | The valley: terrain, lake, forest LOD, cabin, dock, road, the fenced door, sky shader, weather, red sky |
| `src/underground.js` | Vestibule, the shaft and its freight platform, sector building from BadLevel data, entities, the shades, the lantern |
| `src/mesher.js` | Boxes into PS1 meshes on a 2 m grid, with buried/void face culling and per-vertex light baking (occlusion rays) |
| `src/gameplay.js` | Fishing, cooking, chopping, foraging, sleep, energy and health, keycards, relays, workbench, the red-sky trigger |
| `src/hud.js` | Prompts, toasts, bars, menus, notes, maps |
| `src/audio.js` | A fully procedural WebAudio soundscape: rain, wind, birds, frogs, stove, hum, the boom, footsteps. No sample files |
| `src/lore.js` | Every note, the radio, which note goes in which sector |
| `tools/build_sectors.py` | Runs BadLevel with fixed recipes and seeds, writes `assets/sectors/*.json` |
| `tools/fetch_textures.py`, `tools/fetch_models.py` | Rebuild the CC0 texture and model set (Poly Haven, Quaternius) |

To rebuild the sectors you need a BadLevel checkout:

```bash
python3 tools/build_sectors.py --badlevel ../BadLevel
```

**Debug:** add `?debug` to the URL. With it, `&area=hub|b1..b7|lantern` jumps straight
there, and in game **N** toggles noclip, **T** adds an hour, **K** triggers the red sky
and **P** breaks the padlock.
